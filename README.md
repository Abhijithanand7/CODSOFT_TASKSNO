## 🚀 Projects Completed

### 1. Personal Portfolio Website (`Task-1_Portfolio`)
* **Description:** A responsive personal portfolio website showcasing background, technical skill set, academic/practical projects, and contact details.
* **Tech Stack:** HTML5, CSS3 (Flexbox & Responsive Layouts).

### 2. Nexora Landing Page (`Task-2_LandingPage`)
* **Description:** A modern, clean landing page featuring sticky navigation, hero showcase, feature grid, smooth scrolling, and custom interactive authentication alerts.
* **Tech Stack:** HTML5, CSS3 Grid & Flexbox, JavaScript.

### 3. Modern Calculator (`Task-3_Calculator`)
* **Description:** An interactive web-based calculator supporting basic arithmetic operations, real-time expression evaluation, clear/delete functions, and error handling.
* **Tech Stack:** HTML5, CSS3 Grid, JavaScript (DOM Manipulation).
